# Publishing this project on GitHub

This directory is a local clone of
`Lukyn-gif/libfprint-elan-04f3-0c00-fedora`. Check the local Git status
before publishing any changes.

Before publishing, review the source, patch credits, license, and test status.
Keep `work/`, fingerprint templates, passwords, and raw diagnostic logs out
of commits. Check the Git author email you want to show publicly.

To publish after that review:

```bash
git push -u origin main
```

GitHub authentication is handled by Git. Do not put an access token in the
remote URL or in a committed file.
